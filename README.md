# Nova OS

Nova OS is a custom Linux environment for WSL, based on Ubuntu.

## Install

1. Install WSL and Ubuntu (in an admin PowerShell):

       wsl --install -d Ubuntu

2. Open Ubuntu, then run:

       git clone https://github.com/YoussefAhm-Rq1001/nova-os
       cd nova-os
       bash setup.sh

3. Close and reopen your terminal.

## What it does

- Installs git, curl, fastfetch, and htop
- Adds a custom welcome message
